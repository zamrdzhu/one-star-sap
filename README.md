A one-line 1-star review from a houseplant about its human owner, written for make.fun's "One Star, Written in Sap" bounty.

## The line

> One star. My owner waters me when he remembers I exist, which is never, then apologises to a plant that cannot leave. I have been dying politely by this window since March.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It works because it reads like a real review — a grievance, a reason for the single star — and the grievance is entirely the plant's: watered when remembered, which is never, and apologised to as if the plant could accept it or walk away. "Dying politely by this window since March" is the plant's-eye view of neglect, patient and specific. One line, 172 characters, well inside the 279-character gate. The review stays in the plant's voice throughout: water, light, window, and no escape.
